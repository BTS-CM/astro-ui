## Common operations

- `liquidity_pool_exchange` — swap through a pool.
- `liquidity_pool_deposit` / `liquidity_pool_withdraw` — stake and unstake.
- `liquidity_pool_create` — deploy a pool (see [Create Liquidity Pool](/docs/asset-creation/create_liquidity_pool.html)).

Pools, Custom Pool Tracker and Top Pools are **read-only viewers** — they never broadcast transactions.
